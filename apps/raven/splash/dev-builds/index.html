Dev builds

Every release of raven, newest first, with the files that install it: Raven for Mac and Windows, and the device app for Android TV. Every build signs in at raven, so you need an approved account.

  • Android TV

    1. Install Downloader from the Play Store on the TV.
    2. In the TV's settings, allow Downloader to install unknown apps.
    3. In Downloader, open maester.netlify.app/tv and pick the newest APK.

    A newer APK installs over the one you have and keeps your sign-in.

  • Apple TV, iPhone and iPad

    Apple devices take test builds through TestFlight, not as a file. The invitation will be posted here once raven's TestFlight is open.

Asking GitHub for the list.
