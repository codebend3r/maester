Dev builds

Every release of Raven, newest first, with the files that install it: Raven for Mac and Windows, the device app for Android TV and Android phones, and Wren for Android phones. Every build signs in at Raven, so you need an approved account.

  • Android TV

    1. Install Downloader from the Play Store on the TV.
    2. In the TV's settings, allow Downloader to install unknown apps.
    3. In Downloader, open maester.tv/tv and pick the newest APK.

    A newer APK installs over the one you have and keeps your sign-in.

  • Android phones

    1. On the phone, open maester.tv/dev-builds in the browser.
    2. Download the newest Android phones APK for Raven, or the Wren APK for music.
    3. Open the download and allow the browser to install unknown apps when asked.

    A newer APK installs over the one you have and keeps your sign-in.

  • Apple TV, iPhone and iPad

    Apple devices take test builds through TestFlight, not as a file. The invitation will be posted here once Raven's TestFlight is open.

Asking GitHub for the list.
