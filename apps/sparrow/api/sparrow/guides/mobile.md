# iPhone, iPad and Android phones

1. Install **Plex** from the **App Store** (iPhone, iPad) or **Google Play** (Android).
2. Open it and sign in with your Plex account.
3. The server's libraries show up once you've accepted the invite. If you only see Plex's own movies and shows, open the sidebar or the **More** tab and pick the server's libraries there.

On mobile data, set the **cellular** or **remote** quality lower (see below) so a film doesn't eat your data plan. Phones play most files directly; big 4K remuxes are better on a TV.
